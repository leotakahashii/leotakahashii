### 👨🏻‍💻 Sobre mim

Tenho 26 anos, moro no Rio de Janeiro e estou em transição de carreira: depois de um tempo trabalhando com gastronomia, decidi seguir tecnologia como objetivo de longo prazo. Hoje curso **Ciência da Computação** e estudo Full Stack de forma autodidata, com foco atual em **Java, Spring Boot e back-end** (além de HTML, CSS, JavaScript, React, PostgreSQL e IA aplicada ao desenvolvimento).

Aqui compartilho os projetos que construo ao longo dessa jornada — do back-end com Java/Spring a integrações com APIs de clima e IA.

- 🔭 Atualmente construindo o **movement-academy-api** (Java 21 + Spring Boot + PostgreSQL), uma API REST de gestão de academia, camada por camada, para entender a arquitetura back-end a fundo
- 🌱 Aprofundando conhecimento em Java, Spring Boot e banco de dados relacionais
